# УМОК Помощник

Программа удалённой помощи онлайн-школы [УМОК](https://umokschool.ru). Ученик ставит её на свой компьютер, и педагог прямо из видеоурока может с разрешения ученика посмотреть его экран и помочь: показать, где нажать, поправить настройку, разобрать код.

Это сборка открытого проекта [RustDesk](https://github.com/rustdesk/rustdesk) со своим сервером школы и фирменным оформлением. Исходный код открыт по лицензии AGPL-3.0 (файл `LICENCE`), как и у RustDesk.

## Скачать

Готовые сборки - на странице [Releases](https://github.com/ef1m03/umok-helper/releases/latest):

| Файл | Для чего |
|---|---|
| `UMOK-Helper-install.exe` | Windows 10/11, установщик (рекомендуется) |
| `UMOK-Helper.exe` | Windows, запуск без установки |
| `UMOK-Helper-mac-arm64.dmg` | Mac на Apple Silicon (M1-M5) |
| `UMOK-Helper-mac-x64.dmg` | Mac на Intel |
| `SHA256SUMS.txt` | контрольные суммы файлов |

Ученикам и родителям удобнее ставить программу со страницы «Помощник» в личном кабинете школы: там пошаговая инструкция для Windows и Mac.

## Чем отличается от RustDesk

- Встроены адрес и ключ сервера школы - ничего не нужно настраивать вручную.
- Название, значки и тексты «УМОК Помощник».
- Скрыто поле одноразового пароля: подключение разрешает сам ученик кнопкой во время урока.
- Mac-сборки подписаны локально (ad-hoc), поэтому при первом запуске Mac попросит подтвердить открытие в «Системные настройки -> Конфиденциальность и безопасность».

## Как собирается

Ветка `umok`, сборка - GitHub Actions, файл `.github/workflows/umok-build.yml`:

- пуш в ветку `umok` - проверочная сборка для Windows x64 и Mac (arm64, x64) с проверкой, что в программу вшиты сервер и ключ школы, и пробным запуском на чистой Windows;
- тег `umok-vX.Y.Z` - сборка и публикация релиза.

Сервер подключений (hbbs/hbbr) работает на видеосервере школы, инструкция - в основном репозитории платформы, `deploy/rustdesk/`.
